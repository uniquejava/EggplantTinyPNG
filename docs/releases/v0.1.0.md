# EggplantTinyPNG v0.1.0

## English

Drop in photos. Get smaller files. Everything stays on your Mac — nothing is uploaded.

### What you can do

- Drop or choose **PNG, JPEG, or WebP**
- Compressed copies appear next to the originals as `name-tiny.ext` (you can turn auto-save off in the menu)
- Watch progress for a whole batch; jump to any result in Finder
- Pick a look and language in Settings

Closing the window does not quit the app. Press ⌘Q when you’re done.

### Install

1. Download **EggplantTinyPNG-v0.1.0.dmg**
2. Open it and drag the app into **Applications**
3. If macOS says it can’t be opened, run once in Terminal:

   `xattr -cr /Applications/EggplantTinyPNG.app`

4. For better PNG results, install helpers once (needs [Homebrew](https://brew.sh)):

   `brew install pngquant oxipng`

### Needs

- A Mac running **macOS 15** or later
- This build is signed for personal use and is **not** notarized by Apple

## 简体中文

把图片拖进去，得到更小的文件。全程在你自己的 Mac 上完成，不会上传到任何地方。

### 能做什么

- 拖入或选择 **PNG、JPEG、WebP**
- 压缩结果自动保存在原图旁边，文件名是 `原名-tiny.ext`（也可在菜单里关掉自动保存）
- 一次压多张也能看进度；点一下就能在 Finder 里找到结果
- 设置里可以换主题和语言

关掉窗口不会退出；要退出请按 ⌘Q。

### 安装

1. 下载 **EggplantTinyPNG-v0.1.0.dmg**
2. 打开后把应用拖进 **应用程序**
3. 如果系统提示无法打开，在终端执行一次：

   `xattr -cr /Applications/EggplantTinyPNG.app`

4. 想要更好的 PNG 效果，装一次本机工具（需要先有 [Homebrew](https://brew.sh)）：

   `brew install pngquant oxipng`

### 运行环境

- 需要 **macOS 15** 或更新系统
- 当前为个人签名版本，**未经** Apple 公证
