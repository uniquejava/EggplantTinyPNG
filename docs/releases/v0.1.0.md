# EggplantTinyPNG v0.1.0

## English

First public release of **EggplantTinyPNG** — a native macOS 15+ TinyPNG-style compressor that runs entirely on your Mac.

### Highlights

- Drag or open **PNG · JPEG · WebP**; compress locally (no cloud API)
- PNG via **pngquant** (+ optional **oxipng**), same approach as obsidian-cos-images
- **Auto export** beside the original as `name-tiny-yyyyMMdd-HHmmss.ext` (⌘E), or manual **Export All**
- Queue with overall progress and per-row Finder reveal
- Themes and language (System / English / 简体中文) in Settings
- Standard **Dock** app — closing the window keeps the app; ⌘Q to quit

### Install

1. Download `EggplantTinyPNG-v0.1.0.dmg`
2. Open the DMG and drag the app to **Applications**
3. If Gatekeeper blocks it: `xattr -cr /Applications/EggplantTinyPNG.app`
4. Install CLI tools if needed: `brew install pngquant oxipng`

### Requirements

- macOS 15+
- Ad-hoc signed (not notarized)

## 简体中文

**EggplantTinyPNG** 首个公开发布 — 原生 macOS 15+ TinyPNG 风格图片压缩工具，全程本地处理。

### 亮点

- 拖拽或打开 **PNG · JPEG · WebP**；本地压缩（不调用在线 API）
- PNG 使用 **pngquant**（可选再跑 **oxipng**），与 obsidian-cos-images 同思路
- **自动导出**到原图旁：`name-tiny-yyyyMMdd-HHmmss.ext`（⌘E），或手动 **全部导出**
- 压缩队列、总体进度、导出后可在 Finder 中显示
- 设置内可选主题与界面语言（跟随系统 / English / 简体中文）
- 标准 **Dock** 应用 — 关窗口不退出；⌘Q 才退出

### 安装

1. 下载 `EggplantTinyPNG-v0.1.0.dmg`
2. 打开 DMG，将应用拖到 **应用程序**
3. 若被 Gatekeeper 拦截：`xattr -cr /Applications/EggplantTinyPNG.app`
4. 按需安装命令行工具：`brew install pngquant oxipng`

### 系统要求

- macOS 15+
- ad-hoc 签名（**未**公证）
